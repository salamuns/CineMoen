# CineMoen

Aplikasi Android (WebView) dengan pilihan alamat situs.

## Build APK lewat GitHub Actions
1. Push repo ini ke GitHub.
2. Buka tab **Actions** → workflow **Build APK** (jalan otomatis setiap push, atau klik **Run workflow**).
3. Setelah selesai, buka run tersebut dan unduh **CineMoen-apk** di bagian *Artifacts*.
4. Ekstrak zip-nya, lalu install `CineMoen.apk` di HP.

## Build lokal
Buka folder ini di Android Studio, lalu **Build → Build APK(s)** (file bernama `app-debug.apk`).
